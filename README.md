# 🤖 AI Sentiment Analyzer

A lightweight, interactive web application built with Python, Streamlit, and Hugging Face Transformers to perform real-time sentiment analysis on text inputs.

## 🚀 Features
* **AI-Powered:** Uses pre-trained deep learning models from Hugging Face.
* **Interactive UI:** Clean and responsive web interface built using Streamlit.
* **Instant Results:** Real-time classification with confidence scores.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (Web framework)
* **Hugging Face Transformers** (AI Model Pipeline)
